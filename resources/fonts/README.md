# Kalpurush font file goes here

This folder needs `Kalpurush.ttf` for mPDF to render Bengali PDFs correctly
(certificates, reports, activity log exports).

Download it from:
https://fonts.maateen.me/kalpurush/Kalpurush-v0.258.ttf

Save it in this folder as exactly: `Kalpurush.ttf`

(Not included in this delivery — binary font files can't be reliably
transferred through the tooling used to generate this project. See README.md
section "Phase 13" for the full mPDF setup steps.)
